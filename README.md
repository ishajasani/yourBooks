# **YourBooks**
YourBooks is a web application for managing books efficiently. This platform allows users to create, read, update, and delete (CRUD) book records while offering an intuitive interface and seamless user experience. 

---

## **Features**
1. Add New Books: Add detailed information about new books, including title, author, genre, and publication year.
2. View Books: Browse all available books in a list format with quick search and filter options.
3. Update Books: Modify book details with real-time updates.
4. Delete Books: Remove unwanted book entries from the database.

---

## **Technologies Used**
- Frontend: React
- Backend: ExpressJS
- Database: MongoDB
- Styling: Bootstrap
